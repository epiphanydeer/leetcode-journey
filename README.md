# LeetCode Journey

Built from the [eight-stage core route](https://leetcode.cn/discuss/post/3141566/ru-he-ke-xue-shua-ti-by-endlesscheng-q3yd/).

The guide groups sliding-window and two-pointer problems in one source article; this repository separates them into `01_sliding_window` and `02_two_pointers` for focused practice. All public problems in the selected sections are included, paid problems are skipped, and a problem that appears in more than one topic only needs to be solved once.
